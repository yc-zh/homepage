Research

Weakly Supervised Object Detection for Tooth-marked Tongue Recognition (1st Author) (2023.9 - 2024.6)
  • Technologies: Weakly Supervised Learning, Vision Transformer, SAM, YOLOv8, Multi-Instance Learning (MIL).
  • Goal: Develop an automatic, accurate system for identifying tooth-marked tongues in TCM tongue diagnosis.
  • Progress & Contribution: Combined YOLOv8 and SAM for efficient tongue segmentation preprocessing. Proposed a ViT and MIL-based method using image patches as candidates, achieving localization with image-level labels. Designed a Patch-Box merging algorithm for objective quantification. [Code]
Multi-stage Self-Attention Network for Tooth Instance Segmentation (1st Author) (2022.11 - 2023.5)
  • Technologies: 3D Instance Segmentation, Self-Attention, UNETR++, Multi-task Learning.
  • Goal: Achieve precise 3D CBCT tooth segmentation to support clinical analysis.
  • Progress & Contribution: Designed a three-stage instance segmentation network. Introduced self-attention for global dependency capture and combined it with a multi-task learning strategy (predicting centroid offsets and skeleton) to effectively separate adjacent teeth. [Paper]
Long-Tailed Out-of-Distribution Detection (3rd Author) (2023.12 - 2024.8)
  • Technologies: OOD Detection, Long-Tailed Recognition, Representation Learning.
  • Goal: Improve OOD detection performance in long-tailed data scenarios.
  • Progress & Contribution: Participated in the implementation and analysis of the PATT algorithm, focusing on enhancing tail-class feature discrimination. [Code]
3D CBCT Alveolar Bone Resorption Rate and Root Canal Length Calculation (2024.8 - 2024.12)
  • Technologies: 3D Segmentation (V-Net), 3D Skeletonization, Keypoint Extraction.
  • Goal: Perform 3D quantitative analysis of segmented alveolar bone and tooth roots.
  • Progress & Contribution: Trained 3D segmentation models. Designed and implemented algorithms for automatic calculation of alveolar bone resorption rate and tooth root canal length measurement based on 3D skeleton keypoint extraction.
